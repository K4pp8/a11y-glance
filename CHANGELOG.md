# Changelog

## 0.1.0 — 2026-11-06

Initial open-source preview.

- On-demand Chrome side-panel inspection with local axe-core scanning.
- Grouped element findings, optional page markers, and separate review results.
- Full-scan, selected-element, and individual-finding Markdown downloads.
- Light/dark design, keyboard interactions, stale-state handling, and reduced-motion support.
- Original SVG icon, design specification, test plan, architecture, and contribution documentation.

Not published to the Chrome Web Store. Manual platform checks remain tracked in `test.md`.
